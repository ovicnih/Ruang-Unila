# Project Brief - Ruang Unila

## Core Requirements
Sistem informasi berita kampus Universitas Lampung yang aman dan cepat.

## Goals
- Platform utama komunikasi kampus
- 6 kategori: Populer, Kampus, UKM, Akademik, Event, Tren
- Manajemen event lengkap (publikasi, pendaftaran, pembayaran)
- Setting profile untuk user

## Scope
- 3 Aktor: Mahasiswa, Organisasi, Admin
- Tech Stack: PHP 8.x, MySQL 8.0, HTML5/CSS3/JS
- Database: ruangunila (5 tabel: users, news, events, event_registrations, categories)
