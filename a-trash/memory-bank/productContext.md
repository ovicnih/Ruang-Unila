# Product Context - Ruang Unila

## Why This Project Exists
- Memfasilitasi komunikasi antara mahasiswa, organisasi, dan admin kampus
- Menyediakan platform terpusat untuk berita dan event kampus

## Problems It Solves
- Informasi kampus yang tersebar dan sulit diakses
- Tidak ada sistem terpusat untuk pendaftaran event
- Proses pembayaran event yang manual

## How It Should Work
- User bisa akses berita berdasarkan 6 kategori
- Organisasi bisa buat event dan kelola pendaftaran
- Admin memvalidasi konten sebelum publish

## User Experience Goals
- Interface intuitif dengan font Manrope
- Responsive untuk mobile, tablet, desktop
- Loading cepat dengan lazy loading untuk gambar
