# Tech Context - Ruang Unila

## Technologies Used
- **Backend**: PHP 8.x (Native/Modular)
- **Database**: MySQL 8.0
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Font**: Manrope (Google Fonts)
- **Server**: Apache/Nginx (Laragon)

## Development Setup
- Local Server: Laragon (MySQL, Apache)
- IDE: VS Code dengan Cline extension
- Database Management: phpMyAdmin
- Version Control: Git

## Technical Constraints
- File maksimal 500 baris
- Wajib Prepared Statements (PDO)
- Dilarang SELECT *
- Lazy loading untuk gambar
- Unit testing untuk fungsi baru

## Dependencies
- PDO extension untuk MySQL
- GD/ImageMagick untuk image processing
- Google Fonts (Manrope)

## Tool Usage Patterns
- MCP MySQL untuk akses database
- Cline untuk development assistance
