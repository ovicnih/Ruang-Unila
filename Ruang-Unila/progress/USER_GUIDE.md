## Untuk Mahasiswa

### 🚀 Memulai
1. Buka browser dan akses: `http://localhost/WEBUNILA/Ruang-Unila/`
2. Klik tombol **"Daftar"** di pojok kanan atas
3. Isi form registrasi:
   - Username (huruf, angka, underscore)
   - Email aktif
   - Password (min. 8 karakter, huruf besar+kecil+angka)
   - Nama lengkap
   - Pilih role: **Mahasiswa**
4. Klik **"Daftar"**
5. Login dengan akun yang baru dibuat

### 📰 Membaca Berita
1. Klik **"Berita"** di menu navigasi
2. Pilih kategori: Populer, Kampus, UKM, Akademik, Event, atau Tren
3. Klik judul berita untuk membaca lengkap
4. Gunakan tombol share untuk membagikan ke media sosial

### 📅 Mendaftar Event
1. Klik **"Event"** di menu navigasi
2. Lihat daftar event yang akan datang
3. Klik **"Lihat Detail"** pada event yang diminati
4. Cek informasi:
   - Tanggal & waktu
   - Lokasi
   - Biaya pendaftaran
   - Kuota tersisa
   - Deadline pendaftaran
5. Klik **"Daftar Sekarang"**
6. Isi catatan jika ada (opsional)
7. Centang persetujuan syarat & ketentuan
8. Klik **"Konfirmasi Pendaftaran"**

### 💳 Pembayaran Event (Jika Berbayar)
1. Setelah mendaftar, Anda akan diarahkan ke halaman pembayaran
2. Transfer sesuai nominal yang tertera ke rekening yang tercantum
3. Upload bukti pembayaran (JPG/PNG, maks. 2MB)
4. Tunggu verifikasi dari admin (1x24 jam)
5. Cek status di **"Pendaftaran Saya"**

### 🎫 Melihat Tiket
1. Setelah pembayaran diverifikasi, buka **"Pendaftaran Saya"**
2. Klik tombol **"Tiket"** pada event yang sudah terkonfirmasi
3. Download atau simpan tiket Anda

### 👤 Mengelola Profil
1. Klik **"Profil"** di menu
2. Klik **"Edit Profil"** untuk mengubah:
   - Nama lengkap
   - Email
   - Nomor telepon
   - Bio
3. Klik **"Ubah Foto"** untuk upload foto profil baru
4. Klik **"Ubah Password"** untuk ganti password

## Untuk Organisasi

### 🚀 Memulai
1. Daftar dengan role **"Organisasi"**
2. Login ke sistem
3. Akses fitur khusus organisasi melalui menu

### 📰 Membuat Berita
1. Klik **"Profil"** → **"Kelola Berita"**
2. Klik **"Tambah Berita"**
3. Isi form:
   - **Judul**: Minimal 10 karakter
   - **Kategori**: Pilih dari 6 kategori
   - **Gambar**: Upload gambar (JPG/PNG, maks. 2MB)
   - **Konten**: Tulis berita lengkap
   - **Status**: Draft atau Submit untuk Review
4. Klik **"Simpan Berita"**
5. Admin akan mereview berita Anda
6. Notifikasi akan muncul jika berita disetujui/ditolak

### 📅 Membuat Event
1. Klik **"Profil"** → **"Buat Event"**
2. Isi form event:
   - **Judul Event**: Minimal 10 karakter
   - **Deskripsi**: Jelaskan detail event
   - **Lokasi**: Tempat pelaksanaan
   - **Tanggal Event**: Pilih tanggal & waktu
   - **Deadline Pendaftaran**: Harus sebelum tanggal event
   - **Kuota Peserta**: Maks. 1000 orang
   - **Biaya**: Isi 0 jika gratis
   - **Gambar**: Upload poster event
3. Klik **"Simpan Event"**
4. Admin akan mereview event Anda
5. Setelah disetujui, event akan muncul di daftar event

### 📊 Melihat Statistik
1. Buka **"Profil"**
2. Lihat statistik:
   - Jumlah berita dibuat
   - Berita yang sudah publish
   - Jumlah event dibuat

### ✏️ Mengelola Berita
1. Buka **"Kelola Berita"**
2. Lihat daftar berita Anda
3. Klik **"Edit"** untuk mengubah
4. Klik **"Hapus"** untuk menghapus (perlu konfirmasi)
5. Cek status: Draft, Pending, Published, Rejected

## Untuk Admin

### 🚀 Login sebagai Admin
1. Login dengan akun admin
2. Username: `admin`
3. Password: `admin123`

### ✅ Memvalidasi Berita
1. Klik menu admin (jika tersedia)
2. Lihat berita dengan status **"Pending"**
3. Klik berita untuk preview
4. Pilih aksi:
   - **Setujui**: Berita akan dipublish
   - **Tolak**: Berikan alasan penolakan
5. Penulis akan menerima notifikasi

### ✅ Memvalidasi Event
1. Akses halaman validasi event
2. Lihat event dengan status **"Pending"**
3. Review detail event:
   - Judul & deskripsi
   - Tanggal & lokasi
   - Kuota & biaya
4. Pilih aksi:
   - **Setujui**: Event akan dipublish
   - **Tolak**: Berikan alasan penolakan

### 💳 Verifikasi Pembayaran
1. Akses halaman verifikasi pembayaran
2. Lihat pendaftaran dengan status **"Menunggu Verifikasi"**
3. Klik untuk preview bukti pembayaran
4. Verifikasi keaslian bukti
5. Pilih aksi:
   - **Verifikasi**: Pembayaran diterima
   - **Tolak**: Berikan alasan penolakan
6. Peserta akan menerima notifikasi

### 👥 Mengelola User
1. Akses dashboard admin
2. Lihat daftar semua user
3. Filter berdasarkan role
4. Aktifkan/nonaktifkan akun user

### 📊 Monitoring
1. Pantau statistik sistem:
   - Jumlah user aktif
   - Berita published
   - Event upcoming
   - Pendaftaran event
2. Cek log error
3. Monitor performa database

## FAQ

### Umum

**Q: Bagaimana cara mendaftar?**
A: Klik tombol "Daftar" di pojok kanan atas, isi form, dan pilih role Anda.

**Q: Lupa password?**
A: Hubungi admin untuk reset password.

**Q: Bisakah mengubah role setelah mendaftar?**
A: Tidak, role ditetapkan saat registrasi. Hubungi admin untuk perubahan.

### Berita

**Q: Berapa lama review berita?**
A: Biasanya 1x24 jam.

**Q: Mengapa berita saya ditolak?**
A: Cek alasan penolakan di halaman "Kelola Berita". Perbaiki dan submit ulang.

**Q: Bisakah mengedit berita yang sudah publish?**
A: Ya, edit akan mengubah status menjadi "Pending" untuk review ulang.

### Event

**Q: Bagaimana jika event sudah penuh?**
A: Anda tidak bisa mendaftar jika kuota sudah habis.

**Q: Bisakah membatalkan pendaftaran?**
A: Hubungi admin untuk pembatalan.

**Q: Bagaimana jika pembayaran ditolak?**
A: Upload ulang bukti pembayaran yang valid.

**Q: Berapa lama verifikasi pembayaran?**
A: Maksimal 1x24 jam.

### Profil

**Q: Format foto profil yang diizinkan?**
A: JPG atau PNG, maksimal 2MB.

**Q: Bisakah mengubah username?**
A: Tidak, username tidak dapat diubah.

**Q: Persyaratan password?**
A: Minimal 8 karakter, harus mengandung huruf besar, huruf kecil, dan angka.

## Troubleshooting

### Masalah Login

**Masalah:** "Username atau password salah"
- Pastikan caps lock tidak aktif
- Cek penulisan username
- Hubungi admin jika lupa password

**Masalah:** "Akun tidak aktif"
- Hubungi admin untuk aktivasi akun

### Masalah Registrasi

**Masalah:** "Username sudah digunakan"
- Pilih username lain

**Masalah:** "Email sudah terdaftar"
- Gunakan email lain atau login dengan email tersebut

**Masalah:** "Format email tidak valid"
- Pastikan format: nama@domain.com

### Masalah Berita

**Masalah:** "Gagal upload gambar"
- Cek format file (harus JPG/PNG)
- Cek ukuran file (maks. 2MB)
- Pastikan file tidak corrupt

**Masalah:** "Berita tidak muncul"
- Berita perlu disetujui admin dulu
- Cek status di "Kelola Berita"

### Masalah Event

**Masalah:** "Tidak bisa mendaftar event"
- Cek apakah kuota masih tersedia
- Cek apakah deadline sudah lewat
- Pastikan sudah login

**Masalah:** "Pembayaran tidak terverifikasi"
- Pastikan bukti pembayaran jelas
- Nominal harus sesuai
- Tunggu maksimal 1x24 jam

### Masalah Umum

**Masalah:** "Halaman tidak bisa diakses"
- Cek koneksi internet
- Pastikan XAMPP/Apache running
- Clear cache browser

**Masalah:** "Session expired"
- Login ulang
- Session timeout 2 jam

**Masalah:** "Upload gagal"
- Cek ukuran file (maks. 2MB)
- Cek format file
- Cek permission folder upload
